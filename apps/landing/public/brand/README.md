# Recount logo package

All files are plain vector SVG with transparent backgrounds, except the app icon, which has its own tile. They need no fonts.

## Files

| File                            | Use on                                                     | Aspect              |
| ------------------------------- | ---------------------------------------------------------- | ------------------- |
| `recount-lockup-on-light.svg`   | White and light backgrounds                                | 256 × 60 (4.27 : 1) |
| `recount-lockup-on-dark.svg`    | Black and dark backgrounds                                 | 256 × 60 (4.27 : 1) |
| `recount-wordmark-on-light.svg` | Light backgrounds, where the symbol already appears nearby | 193 × 52            |
| `recount-wordmark-on-dark.svg`  | Dark backgrounds, where the symbol already appears nearby  | 193 × 52            |
| `recount-symbol-on-light.svg`   | Light backgrounds, small spaces, avatars                   | 1 : 1               |
| `recount-symbol-on-dark.svg`    | Dark backgrounds                                           | 1 : 1               |
| `recount-symbol-teal.svg`       | Light backgrounds, as a single accent                      | 1 : 1               |
| `recount-app-icon.svg`          | App and home-screen icons, any background                  | 1 : 1               |

Use the horizontal lockup by default.

The current lockup and wordmark files include an optical correction to the R. The right corners of its counter now curve with the bowl, so the bowl wall has the same thickness all the way round. Nothing else changed. If you have older copies, replace them with these.

## Colors

- Slate ink `#0F172A`: logo on light backgrounds
- Frost `#F8FAFC`: logo on dark backgrounds
- Tide teal `#0F766E`: accent symbol, light backgrounds only
- Deep tide `#0B4F4A` and mist `#E3EEF0`: app icon tile and symbol

Pick the file that matches the background. Don't recolor a file.

## Clearspace

Every file already includes the minimum clearspace as transparent padding. That padding is one Lattice stroke wide, or 1/6 of the symbol's height. When you place a logo next to other content, leave at least that much space again.

## Minimum size

- Lockup: 96px wide (about 22px tall)
- Wordmark: 64px wide
- Symbol: 16px
- App icon: 32px

## Don't

- Change, redraw or re-space the symbol or the letters
- Stretch a file. Scale it by width or height only, keeping its aspect ratio.
- Retype "Recount" in a font next to the symbol
- Add outlines, shadows, gradients or a second color
- Put a logo on a busy photo or a mid-tone background
