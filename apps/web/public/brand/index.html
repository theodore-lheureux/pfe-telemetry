Recount logo

The Lattice symbol and the Recount wordmark, drawn as vectors. Pick the file for your background and use it as supplied.

Download logo package

Wordmark

Use it where the symbol already appears nearby, for example on a page that has the app icon.

Symbol

Lattice, two linked squares, for small spaces. Teal is for a single accent on a light background.

Scale

The files are shown at real sizes. Don't use a lockup narrower than 96px or a symbol smaller than 16px.

Use

Clearspace
Each file includes padding one Lattice stroke wide. Leave at least that much space again around it.
Aspect
Lockup 256 : 60, wordmark 193 : 52, symbol and icon 1 : 1. Scale by width or height only.
Color
Slate ink on light, frost on dark. Pick the file for the background and don't recolor it.
Geometry
Don't redraw, re-space or retype any part of the logo.
